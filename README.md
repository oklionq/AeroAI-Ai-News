# AI News Agent

Автономный Telegram-бот, который парсит посты из Telegram-канала-донора (@ThePerceptronChannel) через Telethon (Userbot), фильтрует их с помощью LLM (Venice AI / DeepSeek) на предмет важности, генерирует качественные русскоязычные посты и отправляет администратору в ЛС на подтверждение перед публикацией в целевой канал/группу.

## Быстрый старт

1. Установите Python 3.11+
2. Активируйте виртуальное окружение:
   ```powershell
   .\venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Настройте конфигурацию в `.env` (см. `.env.example`).
5. **Однократная авторизация Telethon**:
   ```bash
   python login_telethon.py
   ```
   Скрипт запросит номер телефона, код подтверждения из Telegram и 2FA пароль (если включён), после чего создаст файл сессии `parser_session.session`.
6. Запустите бота:
   ```bash
   python -m bot.main
   ```

## Архитектура и особенности

- **Источник**: открытый канал-донор `@ThePerceptronChannel`.
- **Поддержка альбомов**: сообщения группируются по `grouped_id`, скачиваются фотографии (до 4 шт.), медиа пересылаются в оригинале.
- **Фильтрация рекламы**: автоматическое отсечение рекламных постов (по маркерам `erid:`, `#реклама` и др.).
- **LLM**: Venice AI (`https://api.venice.ai/api/v1`), модель `deepseek-v4-1-flash-1017-uncensored`.
- **Премодерация в ЛС**: каждый сгенерированный пост направляется в ЛС администратору (`ADMIN_CHAT_ID`) с кнопками «✅ Одобрить» (публикует в целевой топик группы `TARGET_GROUP_ID`) и «❌ Отклонить» (с выбором причины).
- **Команды управления**:
  - `/stats` — подробная статистика (собрано, отфильтровано, очередь, опубликовано, отклонено, токены и бюджет).
  - `/queue` — список постов в очереди на проверку.
  - `/cycle` (или `/parsing`) — отчёт по последнему циклу сбора.
  - `/status` — статус бота (активен / на паузе).
  - `/pause` и `/resume` — управление паузой.
  - `/review` — аналитика за 30 дней по категориям и причинам отклонений.
